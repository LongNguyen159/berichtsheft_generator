# Project Description:
For the Azubis: This helps you generate your Berichtsheft by filling in the PDF form automatically.
You don't have to repeatedly enter your school year, name, or even dates and week number. They are automatically calculated. You only have to enter what you did at school as report.
It will generate the PDFs to your desired directory location.

## To compile:
### 1. Install all required dependencies
``` uv sync ```
### 2. Activate Python virtual env (if you haven't)
For windows: ``` .venv\Scripts\activate ```
For UNIX system: ``` source .venv/bin/activate ```

### 3. Run `build.py` script
``` python3 build.py ``` or ```python buld.py```
### 4. Output in /dist folder. This is the executable file.
